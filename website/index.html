01 / Information

The unowned MCP attack surface

MCP servers expose real code, data, and automation paths to autonomous agents.

MCP Guard is a professional security scanner for Model Context Protocol servers. It downloads a target repository, detects the server type, runs static and dynamic analysis, checks dependencies and protocol behavior, then reports vulnerabilities with CVSS v4.0 and AIVSS scoring.

Static analysisPattern-based checks for command injection, path traversal, unsafe functions, auth gaps, secrets, and insecure defaults.
Dynamic testingLive server assessment and fuzzing to catch behavior that static checks alone miss.
Dependency and protocol checksKnown CVEs, package risk, JSON-RPC handling, transport assumptions, and MCP-specific security patterns.
Professional reportsConsole, JSON, SARIF, JUnit, executive summaries, and security gates for CI adoption.

The product focus

AGR is the MCP Guard audit package, not a proxy product.

Nebuless.AGR stays centered on scanner-backed review: discover the MCP server surface, score vulnerabilities, produce evidence, and help teams decide what can ship.

  • Scan: Python, Node, Go, and Docker-based MCP servers.
  • Score: map findings to CVSS v4.0, AIVSS, CWE, severity, business impact, and exploitability.
  • Report: create machine-readable artifacts and executive summaries.
  • Gate: convert critical findings into CI pass or fail criteria before release.
